# DiGraph View Editing Cheat Sheet

## Add vertices
1. Click **Add Vertex** on the toolbar (toggle on).
2. Left-click empty space in the graph view.
3. Enter a label (or accept the default `Vn`).
4. Click **Add Vertex** again to exit add mode.

## Remove vertices
1. Select a vertex (left-click, or Ctrl+click for multi-select).
2. Delete it by either:
   - Right-clicking the vertex and choosing **Delete**, or
   - Pressing the **Delete** key.

> Deleting a vertex also removes edges connected to it.

## Add edges
1. Click **Add Edge** on the toolbar (toggle on).
2. Left-click the **source** vertex.
3. Left-click the **target** vertex.
4. Optionally enter an edge label when prompted.
5. Click **Add Edge** again to exit add mode.

> Notes:
> - The current workflow is mode-based (source click, then target click).
> - Self-edges are blocked by current behavior.

## Remove edges
1. Select an edge.
2. Delete it by either:
   - Right-clicking the edge and choosing **Delete**, or
   - Pressing the **Delete** key.

## Selection tips
- **Ctrl+click** toggles objects in selection.
- Drag on empty space for marquee selection.
